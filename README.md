# 🎗️ AI Breast Cancer Prediction System

An intelligent and user-friendly web application designed to help users understand breast cancer awareness, self-examination, early detection, and AI-based breast cancer risk prediction.

The system provides:

✅ AI-powered prediction  
✅ Breast health assessment  
✅ Breast self-exam awareness  
✅ Early detection guidance  
✅ Healthy lifestyle recommendations  
✅ Medical awareness videos  
✅ Attractive modern UI  

---

# 📌 Features

## 🧠 AI Breast Cancer Prediction
- Predicts breast cancer risk using machine learning
- User-friendly prediction form
- Displays prediction result with risk score
- Dynamic color-based risk indication

---

## 🩺 Breast Health Assessment
Users can:
- Answer health-related questions
- Get instant assessment results
- Receive awareness guidance
- Learn safety measures and precautions

---

## 🎀 Breast Self-Exam Awareness
Includes:
- Step-by-step self-exam guide
- Monthly checking reminders
- Early symptom awareness
- Importance of mammograms

---

## 🥗 Healthy Lifestyle Recommendations
The app suggests:

### ✅ Foods To Eat
- Fruits
- Green vegetables
- Protein-rich foods
- Whole grains

### ❌ Foods To Avoid
- Alcohol
- Smoking
- Junk food
- Highly processed foods

### 🏃 Recommended Exercises
- Walking
- Running
- Yoga
- Meditation
- Daily fitness activities

---

## 🎥 Awareness Videos
Includes educational YouTube videos about:
- Breast cancer symptoms
- Diagnosis
- Self-check methods
- Prevention
- Treatment awareness
